Data Formats

iCalendar

The core calendar data format — events, tasks, recurrences, and time zones (RFC 5545).

vCard

Contact data format — vCard 4.0 and the JSON-based vCard 5.0 / JSContact (RFC 6350, RFC 9553).

jsCalendar

JSON-based calendar data model for web APIs and modern applications (RFC 8984).
