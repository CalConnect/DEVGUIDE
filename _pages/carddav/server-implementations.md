Known CardDAV server implementations.

## Open Source

- **Radicale** — Lightweight Python server.
- **Baikal** — PHP-based server.
- **Sabre/DAV** — PHP framework for CalDAV/CardDAV.
- **Kolab** — Groupware with CardDAV.

## Commercial

- **Google Contacts** — CardDAV access available.
- **Apple iCloud** — CardDAV for Apple Contacts.
- **Fastmail** — CardDAV address book hosting.
