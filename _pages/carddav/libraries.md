CardDAV libraries by language.

## Python

- **vobject** — vCard parsing.
- **caldav** — Also supports CardDAV operations.

## JavaScript / TypeScript

- **tsdav** — CalDAV/CardDAV client.
- **vcard-json** — vCard parsing.

## Java

- **ez-vcard** — vCard parsing and generation.
- **Sabre/DAV** (via PHP bridge)

## PHP

- **Sabre/DAV** — Full CardDAV framework.

## Go

- **go-webdav** — WebDAV/CardDAV client.

## Ruby

- **vcard** — vCard parsing.
