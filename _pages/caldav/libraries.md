CalDAV libraries organized by programming language.

## Python

- **caldav** — Client library for CalDAV operations.
- **icalendar** — iCalendar parsing/generation (used with caldav).
- **vdirsyncer** — CalDAV/CardDAV synchronization tool.

## JavaScript / TypeScript

- **tsdav** — CalDAV/CardDAV client library for TypeScript.
- **ical.js** — iCalendar parsing and validation.

## Java

- **iCal4j** — iCalendar parsing, validation, and CalDAV support.
- **Milton** — WebDAV/CalDAV server framework.
- **Sardine** — WebDAV client (can be extended for CalDAV).

## PHP

- **Sabre/DAV** — Full CalDAV/CardDAV server and client framework.
- **icalcreator** — iCalendar file creation.

## Go

- **go-caldav-client** — CalDAV client library.
- **go-webdav** — WebDAV/CalDAV client library.

## Ruby

- **icalendar** — iCalendar library (Ruby).
- **caldav** — CalDAV client library.

## C/C++

- **libical** — iCalendar library with CalDAV support.
- **Neon** — HTTP/WebDAV client library.
