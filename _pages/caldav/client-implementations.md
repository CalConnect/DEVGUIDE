Known CalDAV client implementations and applications.

## Native Applications

- **Apple Calendar** (macOS, iOS) — Built-in CalDAV support.
- **Mozilla Thunderbird** — Cross-platform email and calendar with CalDAV.
- **Microsoft Outlook** — CalDAV support via third-party plugins or CalDAV Synchronizer.
- **GNOME Evolution** — Linux calendar/email client with native CalDAV.
- **KDE Kontact / KOrganizer** — Linux calendar with CalDAV support.
- **DigiCal** (Android) — Calendar app with CalDAV sync.

## Web Applications

- **Nextcloud Calendar** — Web-based calendar using CalDAV backend.
- **SOGo** — Web mail/calendar with CalDAV support.
